About run history

The title defaults to the main assembly name. Renaming affects only the list display; leave it empty to restore the default. Delete moves a run to the Deleted view and it can be restored at any time; models, evidence, and PRs remain. Earlier integration runs remain in the list.

New delivery run

Select a complete local SolidWorks engineering folder. It is frozen after upload and then runs the seven engineering stages.

File requirements

Limits: 2 GB total, 4096 files, 512 MB per file (platform settings are authoritative). Empty subfolders are not uploaded. Uploads containing ~$ temporary lock files are rejected; close SolidWorks or remove them first. Do not include platform-generated source.json or discovery identity records.
