# 0.3.23 public release validation

This is the first release planned for the public `mimicverse/description-pipeline` repository.
The candidate must pass the source gate, dependency and secret scans, two byte-identical offline
builds, independent distribution checks, native Windows/SolidWorks rehearsal, and release acceptance
before publication. The record will be completed with the published commit and downloaded-asset
SHA-256 values after those checks pass.

The bundled examples are fixtures, not native CAD evidence. Live Onshape acceptance remains deferred
while the account returns HTTP 402. A tool release does not qualify any particular robot for
simulation, training or hardware control.
